PATTERN PRIORITY

What happens when several LEX rules can match the same input? First, LEX chooses the longest match. If two matches have the same length, the rule written first wins.

INPUT ifelse
RULE 01 "if" matches 2 characters
RULE 02 [a-z]+ matches 6 characters
LONGEST MATCH [a-z]+ WINS
THEN — SAME LENGTH
INPUT hello
RULE 01 [a-z]+ matches 5 characters
RULE 02 [a-zA-Z]+ also matches 5 characters
SAME LENGTH FIRST RULE WINS → LOWERCASE
1 LONGEST MATCH → 2 SAME LENGTH? → FIRST RULE WINS
CHARACTER & LINE ANALYSIS

Count characters and lines

A first practical use of LEX: scan the input and keep track of how much text and how many lines were read.

INPUT
Hello LEX
OUTPUT
Characters : 8 Lines : 2
count.l
/* Count characters and lines */
%{
#include <stdio.h>
int char_count = 0, line_count = 0;
%}
%%

[^\n]      { char_count++; }
\n         { line_count++; }

%%

int main() {
    yylex();
    printf("Characters : %d\nLines      : %d\n", char_count, line_count);
    return 0;
}

int yywrap() { return 1; }
